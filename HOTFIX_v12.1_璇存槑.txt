本次修复内容
============

问题：模块化版本的云同步插件仍通过旧版全局变量查找工作台状态，部署时若浏览器缓存或某个脚本未及时加载，会弹出“云同步插件必须放在原工作台脚本之后加载”。

修复：
1. 新增 assets/js/app/runtime-bridge.js，作为工作台与云同步插件之间的稳定接口。
2. supabase-sync.js 不再直接依赖旧版全局变量。
3. 所有本地 CSS/JS 引用增加版本号，避免 GitHub Pages 更新后新旧缓存混用。
4. 错误提示改为明确指出需要检查完整 assets 文件夹。

上传方法：
- 删除或覆盖 GitHub 仓库中旧的 index.html 与 assets 文件夹。
- 上传本压缩包内全部内容到仓库根目录。
- 等待 Pages 部署完成后，按 Ctrl+F5 强制刷新。
- 手机端可清除该网站缓存，或使用无痕窗口先测试。

Supabase 不需要重新建表，不需要重新注册账号。
