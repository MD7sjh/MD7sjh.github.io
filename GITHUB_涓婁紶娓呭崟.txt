GitHub Pages 上传清单
====================

把本文件所在目录里的所有内容上传到 GitHub 仓库根目录。
不要只上传 index.html，也不要额外套一层 dist 文件夹。

必须上传：
- index.html
- .nojekyll
- assets/ 整个文件夹

建议上传：
- README.md
- ARCHITECTURE.md
- supabase/setup.sql
- .gitignore

不应上传：
- 个人 JSON 备份
- service_role / Secret key
- 数据库密码
- 私人 PDF、图片、Word 文档

GitHub 设置：
Settings → Pages → Deploy from a branch → main → /(root)

新增记账模块文件：
- assets/js/modules/accounting.js
- assets/css/accounting.css
这两个文件也必须上传。
