## 旅行规划 Pro

旅行规划仍然是无地图版本，但升级为一个完整的旅行工作区：

- 行程总览：旅行天数、预算、准备进度、住宿、天气和重点事项
- 行程安排：按日期 / 时间管理景点、美食、交通、住宿和拍照
- 出行准备：分类 checklist，并可一键生成常用准备清单
- 天气情况：使用 Open-Meteo 查询目的地当前天气与未来最多 16 天预报
- 住宿推荐：保存候选，并按评分、位置、性价比和舒适度自动排序
- 美食推荐：保存餐馆、必吃菜、评分和预约状态
- 打卡拍照：保存机位、最佳时间、构图想法和器材，并可加入行程
- 旅行碎片：继续保留原来的快速灵感 / 攻略记录
- 计划管理：创建与维护多个旅行计划

旧版 `travel.plans` 与 `travel.notes` 会自动兼容，新结构继续保存在同一个 Supabase `workspace_state.state` JSON 中，不需要修改数据库。
