## v16.1.5 · Project List Simplification

项目看板中的项目列表改为轻量项目清单：

- 顶部只保留进行中、已完成、项目任务、平均进度 4 个核心统计。
- 新建项目表单默认收起，通过“新建项目”按钮展开。
- 项目不再按分类展开成大型横向表格，而是统一显示为单行清单。
- 每行只展示：项目名称、分类、最近更新时间、截止提示、状态、进度、任务数量。
- 支持 全部 / 进行中 / 已完成 / 已暂停 快速筛选。
- 支持关键词搜索，以及按更新时间 / 截止日期 / 完成进度 / 创建时间排序。
- 点击项目行继续筛选下方 Todo List；再次点击同一项目即可取消筛选。
- 详细目标、开始日期、备注等信息继续放在“修改项目”弹窗中，不丢失原数据。

## 旅行规划 Pro

旅行规划仍然是无地图版本，但升级为一个完整的旅行工作区：

- 行程总览：旅行天数、预算、准备进度、住宿、天气和重点事项
- 行程安排：按日期 / 时间管理景点、美食、交通、住宿和拍照
- 出行准备：分类 checklist，并可一键生成常用准备清单
- 天气情况：使用 Open-Meteo 查询目的地当前天气与未来最多 16 天预报
- 住宿推荐：保存候选，并按评分、位置、性价比和舒适度自动排序
- 美食推荐：保存餐馆、必吃菜、评分和预约状态
- 打卡拍照：保存机位、最佳时间、构图想法和器材，并可加入行程
- 旅行碎片：继续保留原来的快速灵感 / 攻略记录
- 计划管理：创建与维护多个旅行计划

旧版 `travel.plans` 与 `travel.notes` 会自动兼容，新结构继续保存在同一个 Supabase `workspace_state.state` JSON 中，不需要修改数据库。

## v16.1.1 美食价位调整

美食模块现在使用「人均消费 + 币种 + 价位定位」，不再使用 `$～$$$$`。旧记录会自动兼容迁移。

## v16.1.4 论文与项目弱关联

- 论文可以选择“独立论文”，完全不关联项目看板。
- 论文也可以手动关联一个已有项目，仅引用项目任务数量与执行进度。
- 新建论文不会自动创建项目。
- 修改论文标题、状态、Venue、截止日期不会改写项目。
- 项目任务完成不会自动写入论文推进日志。
- 删除论文不会删除关联项目；删除项目只会解除论文关联。
- 旧版本自动创建的 `paper:<id>` 项目会一次性迁移为弱关联，并移除旧硬关联标记。


## v16.1.4 · Project Todo Simplification
- 项目看板的任务总表改为轻量 Todo List。
- 快速添加只保留任务名、所属项目、截止日期；高级属性继续通过任务编辑器维护。
- 支持 全部 / 未完成 / 已完成 / 今日 四种快速筛选。
